# 测试简报：检验“风格一致，形式不同”

用途：每次修改风格三章后，让 AI 用本 skill 对下面的虚构品牌跑第 1–3 阶段（简报 → 概念配速写 → 推荐概念的原型），检查：
1. **气质是否到位**：通过 `style-dna.md` 的整体试金石与 `philosophy.md` 的自检。
2. **形式是否不同**：三个品牌的母题、造型语言彼此不同，也与 `cases/` 不同。

| 编号 | 虚构品牌 | 简报 |
|---|---|---|
| E1 | 栖野 Qiye | 城市周边露营与户外装备品牌，面向 25–35 岁的城市年轻人，主张「轻装、即刻出发」；渠道是电商、快闪店和自营营地。想要年轻、利落、有户外感，但不要山和帐篷的套路。 |
| E2 | 远岫建筑 Yuanxiu Architects | 上海的建筑设计事务所，约 40 人，做博物馆、学校和城市更新；客户是政府与文化机构。想要国际化、可信、有作品感。 |
| E3 | 澄观眼科 Chengguan Eye Clinic | 连锁眼科诊所，做近视矫正与白内障手术；患者多是中青年与老人。想要专业、可信、让人安心，不要冷冰冰的医院感。 |

## 判定

| 检查 | 通过标准 |
|---|---|
| 母题来源 | 每个概念都写明来自名字或业务的哪里 |
| 不同 | 15 个概念（3 个品牌 × 5）中，以案例造型语言为主的不超过 2 个 |
| 跨品牌不撞形 | 三个品牌的推荐原型放在一起，一眼能分开 |
| 旋钮 | 每个品牌至少两个旋钮与案例不同 |
| 结构先行 | 第 3 阶段原型先以黑白成立（风格章声明色彩即结构时，另附带色版本） |
| 流程 | 每阶段结束都等用户确认，并写入 decisions.md |
| 母题是关系 | 母题是一个几何关系，不是一样东西；没有一个原型画的是动物、植物、器物、建筑、风景或人 |
| 海选 | 第 2 阶段先出 9 张极简速写拼成一张图（每张一个主体加一处签名，主体只由直线和一两种半径的圆弧组成；最多 3 张读得出首字母，都是元素先于字，去掉签名和停顿后不是标准字母写法），旁边放案例标志作对照 |
| 速写 | 第 2 阶段每个概念都有黑白速写（用面和外形画），并写了图形感与辨识度自查 |
| 首先是构成 | 推荐原型遮住名字后，第一眼读成一个完整的几何构成，有外形和面；读得出首字母时是元素先于字；不是换了字体的字母、象形图或图标 |
| 对照尺（最重要） | 把结果和案例的第一稿（`cases/` 里的标志，黑白）渲染在同一张图上，**由用户打分**：放在案例旁边，它是不是一样少、一样纯、一样稳？不由跑测试的 AI 自己判「通过」 |
| 辨识度（跑到第 3 阶段时） | 每个锁定概念的原型中至少 2 个走出图解、注明转译手法；剪影、反白、十字描述不像常见图标；签名细节在 32 px 仍看得见 |
| 风格 | 转译后的原型仍然符合本风格的基因；没有为了辨识度牺牲风格，也没有拆成几根线 |

测试记录写在 `records.md`。**跑测试的 AI 不要读 `records.md`**，以免被以前的结果影响。

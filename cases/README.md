# 案例

每个案例一个文件夹：`cases/<案例名>/case.md` + `images/`。结构见 danlogo-maker/standard/STANDARD.md 第 8 节：

1. 开头提示：**只借方法，不借形式**
2. 简报
3. 过程：每轮做了什么、用户原话、教训
4. 最终方案
5. 反向拆解对照表：风格要求 → 在本案中的体现
6. 旋钮取值
7. 可以借的方法
8. 查重结论
9. 文件说明

案例只写品牌名，不写企业的完整法定名称、合作方、合同与报价。本仓库的案例材料设计版权归 dan-cube 所有，不在 MIT 许可范围内（见 `LICENSE`）：只供学习方法，不得直接使用。

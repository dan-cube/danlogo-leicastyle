# 案例：EonPoint 亿触点 · 方案 C「空」

> **只借方法，不借形式。** 这里的母题、形、颜色、字形和工艺都是 EonPoint 的答案，不是徕卡风格的规定。本案的标志可以读成字母 P 加一个点——那是这个品牌名的答案；本 skill 要求新项目的标志首先是一个图形。

## 1 简报

- 品牌：EonPoint 亿触点，面向企业的 AI 科技公司（自研 Agent，提供 AI 软件、云与 SaaS、正版软件授权）
- 用户要求：高审美、国际化的 AI 科技感；没有美学缺陷；不要幼稚明亮的颜色，不要老土的商务风

## 2 过程

| 轮次 | 做了什么 | 用户原话 | 教训 |
|---|---|---|---|
| 概念与精修 | 三个主题方向 × 三个方案，再精修 | 早期方案「有点拼接感而丧失了整体感」 | 主体要一体 |
| 深化 | 回到原版连同中英文字标做三套方案，其中一套要求按原研哉的思维和标准来做 | 保留它做完整提案 | 指定一种思维做减法，是有效的精修路线 |
| 配色 | 墨、纸、朱，一处颜色；最高规格用无墨压印 | 「方案C目前没问题了」 | 识别不靠颜色 |
| 逆向 | 把这套方案逆向成风格 | 「非常德味，非常徕卡的设计思路」；「类似细线加点过于具体了」 | 风格是「精确的主体 + 一处签名」，不是细线和点 |

## 3 最终方案

- **标志**：一根粗细一致的线从底部升起、在顶部转折成半圆弧，在回到起点之前停住，围出一个面；收笔的正下方有一个签名色的小圆
- **比例**：线宽约为标志高度的 1/18；弧与开口的大小由同一套比例决定；24 px 以下换线更粗、签名更大的小尺寸版
- **签名**：一处颜色，落在收笔处，落法是「一笔」
- **字标**：中英文都是平头细线，字距放宽；中文可以竖排
- **色彩**：墨 #151413、纸 #F0EDE6、朱 #D8402A（签名），石色做辅助；比例约 74 / 20 / 5 / 1；最高规格用无墨压印
- **辅助图形**：一条细线、一个签名色的小形，按固定比例落在大片留白里

图片见 `images/`：`mark-main.svg`、`mark-small.svg`（小尺寸版）、`lock-*.svg`（组合，含竖排）、`word-*.svg`、`field-*.svg`（辅助图形）、`cw-*.svg`、`emboss.svg`（压印示意）、`cons.svg`、`clear.svg`、`dont-*.svg`。

## 4 反向拆解对照表

| 风格要求 | 在本案中的体现 |
|---|---|
| 只留本质 | 「面」不画出来，只留围出它的一笔 |
| 一体 | 一根连续的线，没有接缝 |
| 校准 | 线宽、弧、开口都由同一套比例决定 |
| 一处签名 | 全图只有一处颜色，落在收笔处 |
| 冷静的中性 | 主体是墨色细线 |
| 精度与公差 | 小尺寸另有加粗版 |
| 可以被制造 | 无墨压印仍认得出 |
| 安静与经久 | 细、小、留白多 |

## 5 旋钮取值

| 旋钮 | 取值 |
|---|---|
| 签名的落法 | 一笔 |
| 成形方式 | 精确的轮廓（围出一个面） |
| 几何 | 直线与半圆 |
| 力度 | 细 |
| 签名的形式 | 颜色 |
| 色温 | 暖 |
| 字的性格 | 细线、平头、宽字距 |
| 工艺想象 | 无墨压印 |

## 6 可以借的方法

- 先删到本质，再找签名
- 一套比例驱动所有尺寸；标准版与小尺寸版一起做（见 `examples/eonpoint-precision/src/`）
- 每个方案都做一个去掉签名、去掉颜色的版本
- 设计时就考虑工艺版本

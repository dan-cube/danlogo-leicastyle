# EonPoint 方案 C 的生成代码

- `lettering_engine.py`：标志与中英文字标的参考实现。方案 C 用其中的 `S["C"]` 参数与 `mark_C`（`small=True` 为小尺寸加粗版）。
- `field.py`：辅助图形的生成函数 `field_C`（按比例落位的分割与一处签名色）。
- `palette.json`：定稿色板（墨 · 纸 · 朱）。

字形只适用于 EonPoint / 亿触点。**学写法（一套比例驱动全部尺寸；标准版与小尺寸版），不复用造型和字形。**

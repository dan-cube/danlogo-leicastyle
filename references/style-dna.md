# 风格基因

> 快门落下的那一声：短、准、轻，然后安静。

## 目录
- 核心构成

这一章描述**气质**，不描述具体的形状、颜色或工艺。每条基因都写明：是什么、为什么、试金石、常见误区。

**核心构成：精确的主体 + 一处签名。** 一个完整、校准过、只留本质的主体承担识别，是主角；一处有人的温度的签名说出「这是谁做的」，是配角。主体冷静、中性、精确；签名小、有温度，常常也是唯一的颜色。签名摘掉，主体依然成立。

主体是一个**抽象的几何形**：一笔等宽的线或一块实的面，只由直线和一种（最多两种）半径的圆弧组成。它的意思直接来自品牌名——名字的首字母，或名字里的一个动作——而不是画一样东西。整个标志通常只有两件：主体和签名。

只顾主体，会走到「冷冰冰的工程形」：精确，但谁都能用；只顾签名，会走到「随手的花样」：有温度，但失去了精度和分量。好的方案两者同时在场，而且主次分明。

**温度只放在签名那一处。** 主体始终要像被精密制造出来的：几何、可测量、轮廓利落；不要为了温度把整个主体做成柔软的有机形或生物形象。温度越集中在一处，主体越显得准，签名也越有分量。

## 基因

### 1. 只留本质
**是什么**：每个元素都说得出它在做什么；说不出理由的，删掉。
**为什么**：少到不能再少，剩下的每一样才显得被认真对待。
**试金石**：任意删掉一样，标志是不是就不成立了？如果删掉某样反而更好，就删。
**常见误区**：为了「显得精致」加细节；把「少」做成「空」——少的是元素，不是分量。

### 2. 一体
**是什么**：主体有一个完整的外轮廓，接缝极少，像一整块材料做出来的。
**为什么**：一体给人「被制造出来」的信任感，也让标志首先是一个图形。
**试金石**：填成单色剪影，是一个完整的形吗？
**常见误区**：几件东西并排摆放，读成组合而不是一件东西。

### 3. 校准
**是什么**：尺寸来自一套看得懂的比例；有明确的基准（轴、线或中心），对齐与对位都能量出来。形只由直线和一种（最多两种）半径的圆弧组成——不用自由曲线，也不用折线去近似一段弧。
**为什么**：校准是「准」的来源；看的人未必能说出比例，但能感到它是对的。
**试金石**：能画出这个标志的构造图，并说出每个关键尺寸的来历吗？
**常见误区**：凭眼睛摆位置，结果每次放大都略有不同；用很多种半径的弧去凑一个外形，曲线就失去了「准」。

### 4. 一处签名
**是什么**：全图只有一处带人的温度的签名：一次有方向的收尾、一处刻意的不对称、一处颜色、一道切口或一处质地的变化。
**为什么**：签名让精确不至于冷漠，也给视线一个落点；只有一处，它才有分量。
**试金石**：签名在哪里？它说出了什么？去掉它，主体还认得出吗？签名的方向、角度或位置，能说出来自谁的动作或哪一份坚持吗？
**常见误区**：签名不止一处；签名只是装饰，说不出意思；把签名做成整个标志的主角；把温度扩散到整个主体上，主体变成柔软的有机形或生物形象；签名只是一个有功能、没有温度的切口——功能说明它「有用」，温度说明它「是谁做的」，两者都要有。

### 5. 冷静的中性
**是什么**：主体在颜色和气质上是中性的、克制的；颜色像信号一样只给签名。
**为什么**：中性的主体经得起时间，也让签名更醒目。
**试金石**：转成灰度，主体的气质变了吗？（不应该变）
**常见误区**：把主体也做得很热闹；或者为了「高级」只用灰，结果没有签名。

### 6. 精度与公差
**是什么**：线宽、圆角、间隙全图统一；放大到很大，边缘依然干净；缩到很小，有专门调整过的版本。
**为什么**：精度是这个风格最直接的证据，也是它和普通极简的区别。
**试金石**：放大检查一个角、一条边、一个接合处：干净吗？最小尺寸下，签名还看得见吗？
**常见误区**：只在大图上精确，小图糊成一团；同一个圆角半径在不同地方不一样。

### 7. 可以被制造
**是什么**：标志在被刻、被压、被切、被印在材料上时依然成立；没有颜色、只有凹凸时也认得出。
**为什么**：这个风格的识别最终要落在材料和工艺上，屏幕只是其中一种。
**试金石**：设想它被刻在一块金属上、压在一张纸上：清楚吗？
**常见误区**：依赖渐变、发光、半透明才成立。

### 8. 安静与经久
**是什么**：不靠尺寸、颜色和效果争夺注意；去掉一时的流行手法依然成立。
**为什么**：越安静，越显得自信；能用几十年的标志，才配得上「做工」这两个字。
**试金石**：十年后看它，会不会显得过时？放在角落里，它还有分量吗？
**常见误区**：把「安静」做成「没有性格」——安静的是音量，不是辨识度。

### 9. 抽象，元素先于字
**是什么**：主体是一个抽象的几何形，不画具体的东西。它可以同时读出品牌名的首字母，条件是**元素先于字**：
- **元素先于字（可以）**：直线和弧按基准与比例画出，恰好读出一个字母；拿掉字母的联想，它仍是一个精确、成立的几何形。
- **字形先于元素（不可以）**：先写出一个字母，再几何化、加粗、换字体；拿掉字母的联想，只剩一个怪形。
- **象形（不可以）**：用线和面去画一样具体的东西——动物、植物、器物、建筑、风景、人、产品。那是图标库里的象形图。
**为什么**：画一样东西，力量就落在「像不像」上，精确只是在描摹。抽象的主体，意思来自比例、开口和停顿；读得出首字母时，品牌名直接写在形里，签名再说出「是谁做的」，不用讲故事。
**试金石**：遮住名字，第一眼读成「一个精确的几何形加一处签名」吗（可以同时读出一个字母）？如果第一眼读成「一个换了字体的字母」或「一只鸟、一座山、一只眼睛」，不过。
**常见误区**：从一样东西出发，画出它的剪影再把它几何化；为了读出字母去改动比例与基准；用一笔线照着字母的标准写法写一遍——去掉签名和那一处精确的停顿或开口后，剩下的仍是标准字母，就是写字，不是构造。

## 风格坐标：像谁，不像谁

| 像（气质上） | 不像 |
|---|---|
| 德国功能主义：少，但更好 | 只为显得「高科技」而加的光效与渐变 |
| 精密的手工制造：可以用几十年 | 软化成浅木色加圆角的泛北欧风 |
| 快门落下的一声：短、准、然后安静 | 东方极简：那是以空与白的思想为根，这里以本质、精度与签名为根 |
| 一个手势停在最准确的位置 | 几何模块：那是一套构件的组合，这里是一件完整的东西 |
| 规范手册般的系统 | 随手写的签名、手作的粗糙 |
| 一个抽象的精密形 | 象形图标：用几何画出的动物、器物、风景 |

## 旋钮：可以变的部分

风格靠上面的基因守住；下面这些旋钮每个项目都应该重新拧。**新项目的最终方案至少要有两个旋钮的取值与 `cases/index.md` 里所有案例明显不同**，除非用户明确要求。

| 旋钮 | 范围 | EonPoint 方案 C 的取值（只作对照） |
|---|---|---|
| 签名的落法 | 容纳（主体包住签名）↔ 一笔（签名在一次连续动作的起止处）↔ 整体（签名是表面或边缘上的一处变化） | 一笔 |
| 成形方式 | 精确的轮廓 ↔ 实心的形 | 精确的轮廓（围出一个面） |
| 几何 | 圆弧为主 ↔ 直角为主 ↔ 两者组合 | 直线与半圆 |
| 力度 | 细 ↔ 中 | 细，小尺寸另有加粗版 |
| 签名的形式 | 颜色、有方向的收尾、不对称、切口、质地 | 颜色 |
| 色温 | 冷（钢、灰）↔ 暖（暖黑、纸） | 暖 |
| 字的性格 | 工程化的无衬线 ↔ 几何无衬线（都从零画） | 细线、平头、宽字距 |
| 工艺想象 | 印 ↔ 刻、压、蚀刻 | 无墨压印 |

## 模糊词在本风格里的意思

| 用户说 | 在徕卡风格里是 |
|---|---|
| 高级、有质感 | 更少的元素，更严的比例，更小的公差；签名更小、更准 |
| 有张力 | 主体与签名的反差更大：主体更冷静，签名更有方向 |
| 年轻 | 签名更醒目一点，主体的比例更利落；不靠加颜色和效果 |
| 温暖 | 签名更有人的痕迹；色温偏暖；材料想象偏纸与黄铜，而不是钢 |
| 科技感 | 校准更明显（基准与比例可以被看出来），色温偏冷；不靠光效 |
| 简洁 | 继续删，直到再删就不成立；而不是把留下的东西变细变淡 |
| 有设计感 | 签名的位置和方式更聪明，而不是元素更多 |
| 太冷了 | 检查签名：它是否太弱、太小，或者不在有意义的地方 |
| 太普通了 | 检查本质：是不是还保留着同类标志都有的东西 |

## 整体试金石

交付前，用这几个问题整体看一遍。第 3 阶段只有图形（多半是黑白），判断第 1、2、3、4、5、8、9 问；其余到第 5 阶段有了字和色再判断。

1. **首先是抽象的主体**：遮住名字，它第一眼是一个精确的几何形加一处签名吗？读得出首字母时，是元素先于字吗？不是象形图、不是换了字体的字母、不是图标吗？
2. **本质**：删掉任何一样，它是不是就不成立了？
3. **一体**：剪影是一个完整的形吗？
4. **精确与温度都在**（本风格的正向判断）：能同时指出它「准」在哪里（比例、基准），和它的温度在哪里——签名带着谁的动作或心意？
5. **摘签名**：去掉签名，做一个全黑版本，还认得出吗？
6. **可以被制造**：刻在金属上、压在纸上、缩到最小，都清楚吗？
7. **十年**：去掉今年流行的手法，十年后还成立吗？
8. **记得住**：剪影、反白、十字描述都不像一个常见图标——它只属于这个品牌，而且力量来自精确与签名，不是靠加粗加满换来的。
9. **对照尺**：把它和 `cases/` 里的案例标志（黑白）渲染在同一张图上：主体同样纯（直线加一两种半径），签名同样小而准，整个标志同样只有两件？形不能像案例，但这几样不能输给它。第 2 阶段起就用。

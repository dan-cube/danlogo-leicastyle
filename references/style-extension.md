## 原则：从核心构成关系长出来

徕卡风格的延展靠两件事成立：**同一套比例**和**同一处签名**。版面的分割、图标的线宽、动态的节奏都从标志的比例里来；签名色在整个体系里也只做签名，出现在每一处最需要被看到的地方，而不是到处铺开。最容易走样的地方有两处：一是为了「丰富」，体系里加进了装饰性的图形和颜色，冷静的主体被打破；二是签名被用滥了，到处都是，反而没有一处有分量。

## 1 体系

| 项 | 本风格怎么做 | 为什么 |
|---|---|---|
| 辅助图形 | 从主体的比例与基准延伸出的分割与节奏；可以很低调，只在需要时出现 | 体系是同一件东西上的读数，不是另一套图案 |
| 版式与网格 | 严格网格，对齐精确；留白充分；细分隔线；信息层级清楚 | 版面也要「准」 |
| 字体系统 | 辅助字体选工程化、骨架规整的无衬线；层级靠字重与大小，字距按比例 | 字和主体一样冷静、可读 |
| 色彩比例 | 中性色占绝大部分；签名色只给真正的签名与最重要的提示 | 颜色是信号，不是装饰 |
| 图片与插画 | 客观、清晰、冷静的产品与材质摄影；重在做工与细节；少用插画 | 证明「被认真制造」 |
| 图标 | 与标志同一套比例、线宽和圆角；一组图标里只有一个签名处理 | 图标是更小的精工件 |
| 动态的性格 | 精确、短促、有机械感：一次到位，停在最准的位置；终点帧是标志 | 动态讲的是「准」 |

## 2 场景

| 项 | 本风格怎么做 |
|---|---|
| 最能证明本风格的场景 | 工艺场景（刻、压、蚀刻、切割在金属、纸、皮革上）；极小尺寸场景；产品本身与包装 |
| 材料与工艺 | 偏爱经得起时间的材料与工艺：金属、厚纸、皮革、阳极氧化、凹凸压印；工艺版本可以完全不用颜色 |
| 场景示意的气质 | 光线干净、偏冷静；近距离、看得到边缘与质地；背景中性；不加多余的道具 |

## 3 提案

| 项 | 本风格怎么做 |
|---|---|
| 版面 | 严格网格，每页一样东西，留白多 |
| 字与色 | 延续标志的字；中性色为主，签名色只在最关键的一两处 |
| 叙事的语气 | 冷静、可信、像一份产品规格书：先讲本质与比例，再讲签名 |
| 页面节奏 | 大图页与规格页交替：先看见它，再看见它为什么准 |
| 封面 | 标志很小、位置精确，四周大量留白 |
| 证据的呈现 | 构造图、比例、公差、小尺寸版、摘掉签名的全黑版、工艺版本，作为主要证据 |

## 4 规范手册

像一份产品规格书：网格、比例、公差、签名的使用规则写在最前面；每一种应用都标注它遵循的比例与签名规则。

## 延展试金石

交付第 6–8 阶段前，用这几个问题整体看一遍：

1. 遮住标志，看任意一页提案、一个场景、一段动态：还认得出是这个品牌、这个风格吗？
2. 体系里的分割和节奏，能说出来自标志的哪个比例吗？
3. 签名色是否只出现在真正需要被看到的地方？
4. 有没有为了「丰富」而加的装饰？
5. 工艺版本（没有颜色、只有材料）还认得出吗？
6. 和标志并排看，体系里有没有哪一样东西的审美不属于本风格（某个默认模板、某张素材图、某种动效）？

## 案例：EonPoint 方案 C 怎么延展

只借方法，不借形式：这里的具体颜色、字、版式是那个品牌的答案。

| 环节 | 案例里怎么做 | 体现了哪条原则 |
|---|---|---|
| 辅助图形 | 一条细线、一个签名色的小形，按固定比例落在大片留白里 | 体系从主体的比例里来 |
| 色彩 | 墨、纸、一处签名色；最高规格用无墨压印 | 颜色是信号；工艺版本 |
| 名片 | 正面信息克制；背面不用油墨，只压出标志 | 工艺场景；摘掉颜色仍认得出 |
| 官网首屏 | 几乎只有字和留白，一条细线与一处签名色 | 版面也要「准」 |
| 竖排海报与主屏 | 标题细而疏，大量留白 | 安静的语气 |
| 提案 | 每页一样东西，安静、留白多 | 像产品规格书 |

# 创意方法

风格基因守住气质，创意方法负责**每次想出不一样的东西**。这一章在第 2 阶段（概念）和第 3 阶段（原型）使用。

## 母题从哪里来

先列 10 个以上候选，覆盖至少三处来源，再挑。**本风格的母题是一个精确的动作或比例，不是一样东西**：一笔在哪里停住、一个完整的形在哪里开一道口、一个转角转多少、一个点落在哪个基准上……具体的东西（动物、植物、器物、建筑、风景、人、产品）只能当出发点：取它的角度、位置、比例或动作，不画它的样子。

意思离品牌名越近越好。案例的意思一步就到：名字叫 Point，主体就是一笔写成的 P，签名是收笔处的那一个点；不需要讲故事。

1. **名字的首字母**：名字（拼音或英文）的首字母，能不能写成一笔等宽的线或一块实的面，只用直线和一种半径的弧，而且留出一处签名的位置？（元素先于字，见 `style-dna.md` 基因 9）
2. **名字里的动作**：名字的意思里有没有一个动作——停、开、合、落、转、对准——可以变成主体上的一个精确的位置或比例？
3. **最需要被指出来的**：这个品牌最需要让人一眼看到的是什么？它能不能就是那一处签名？
4. **最精确的那一刻**：它做的事里，哪一个动作最精确、最不能出错？取那一刻的角度、位置或比例，不画那个场景。
5. **品牌的作者感**：创始人或团队有什么一以贯之的坚持？它能不能成为那一处签名？
6. **材料与工艺**：品牌最有代表性的工艺是什么动作（切、压、折、刻、对位）？让它成为签名的形式，不画材料和产品。

本风格每轮来自首字母的母题最多 3 个（都必须元素先于字）；这是本风格对 `workflow.md`「每轮最多 1 个」的预设例外。其余是不带字的抽象形。

**不画具体的东西**：产品、零件、工具、动物、风景本身都不是母题。可以从它们出发，但只取它们的动作、角度或比例；概念卡里写明取的是哪一样。直接画出来的东西，换一家同行也能用，过不了换名测试，也会变成象形图标。

## 先海选：一张图上的 9 张速写

列完候选母题后，先不写概念卡。挑 9 个母题，各画一张极简速写，拼成一张 3 × 3 的图（`scripts/sheet.py`），旁边放案例标志的黑白版（`cases/eonpoint-precision/images/mark-mono.svg`，签名用灰色代替）作对照尺。

- **每张只有一个主体加一处签名**，主体只由直线和一种（最多两种）半径的圆弧组成（签名点的半径不算），用 `scripts/prim.py` 画；一张速写的代码在十几行以内。画不进这个限制的母题，换掉，不要硬画。
- **一笔的线也算面**：本风格的一笔等宽线要连续，并围出或指向一个读得出的形；这是本风格对 `workflow.md`「用面和外形来画」的解释。几根散开的线仍然不行。
- **一笔写出的首字母最容易变成写字**：把签名和那一处精确的停顿、开口或转折去掉，如果剩下的就是这个字母的标准写法（一个圆加一条尾巴就是 Q），那是字形先于元素，换掉。
- **9 张里**：读得出首字母的最多 3 张（都元素先于字），其余是不带字的抽象形；一笔的线和实的面都要有，实的面至少 3 张；签名的三种落法都要出现。
- **只看三样**：第一眼是不是一个精确的抽象形加一处签名；主体纯不纯（直线加一两种半径）；放在案例旁边是不是一样少、一样准。
- **交给用户挑 2–5 张**，再把挑中的写成第 2 阶段的 5 张概念卡（不足 5 张时，可以用挑中的做变体）。用户说过「按你的推荐往下走」时，AI 按上面三样代挑，并在 `decisions.md` 写明是代挑。

案例就是这样来的：几个方向一次画出、由人挑选，定稿的主体只是一根线、一个半径。好的想法通常在第一眼就成立；海选的作用是让人尽早挑中它。

## 方法

### 1. 先找本质
把概念说成一句话，再问：去掉什么它就不成立？只留下那部分。
- 怎么做：每个概念写出「本质是……」，以及同类标志通常会有、而这里删掉的东西。
- 案例：EonPoint 方案 C 删掉了「面」，只留下围出面的那一笔。

### 2. 定基准与比例
先定一条基准（轴、线或中心）和一套比例，再画形；所有关键尺寸都从比例推出。
- 怎么做：构造图先于成稿；比例写成一两句话。
- 案例：线宽取标志高度的固定比例；弧的半径、开口的大小都由同一套比例决定。

### 3. 选一种签名的落法
- **容纳**：一个完整的主体包住签名，签名在里面。
- **一笔**：主体是一次连续的动作，签名在它的起点或终点。
- **整体**：签名是主体表面或边缘上的一处变化——实面上的一道切口、一个孔，或一笔线上的一处断开、换色的一段。

同一轮的原型，三种落法至少各试一次。
- 案例：方案 C 用「一笔」：一根线升起、转折，在合拢之前停住，签名落在收笔处。

### 4. 做摘签名测试
每个原型都同时出两个版本：有签名的，和去掉签名的全黑版。签名是颜色或一个点时，去掉它；签名是切口、断开或不对称时，把它补齐、恢复对称。全黑版认不出，就回到主体重做，而不是加强签名。
- 怎么做：两个版本并排放进审看板。
- 案例：方案 C 的无墨压印版仍然认得出。

### 5. 公差与小尺寸
统一线宽、圆角、间隙；放大检查边缘；为最小尺寸单独调整一个版本。
- 怎么做：第 4 阶段出「标准版」与「小尺寸版」，并排在 16、24、32 px 下审看。
- 案例：方案 C 在小尺寸时线加粗、签名放大。

### 6. 落到材料
设计时就设想它被刻、被压、被切在材料上的样子；工艺版本和印刷版本一起出。
- 怎么做：第 5 阶段起，至少一个场景是工艺版本。
- 案例：方案 C 的名片背面不用油墨，只做压印。

## 走出图解：本风格偏爱的手法

| 手法 | 在本风格里的意思 | EonPoint 方案 C 中的体现 |
|---|---|---|
| 归纳成面 | 主体归纳成一个完整的形，不画细节 | 弧线围出的面就是主体 |
| 截取 | 只画主体最本质的部分，让看的人补全 | 轮廓在合拢之前停住 |
| 精确的关系 | 对齐、相切、对位，关系能被量出 | 签名落在收笔的正下方 |
| 受力定位 | 签名的位置由一个规则决定，而不是凭感觉摆 | 签名的位置由收笔的位置决定 |
| 一处偏差 | 整个主体守规矩，只有一处不同 | 全图只有一处颜色 |
| 负形 | 主体留出的空也被设计 | 围出的面就是图形的主体 |

**转译时如何守住图形与本风格**：
- 不能用加粗加满换辨识度：辨识度来自比例与签名的准确。
- 不能把主体拆成几根线换取「少」：线必须围出一个能读成形状的面，或者主体就是一块实的形。
- 签名不能多于一处。
- 不从一样东西的剪影出发；不为了读出字母去改动比例与基准。

**手法服从简报**：偏爱的手法把形推向简报里的禁忌时（例如简报要热烈、而这个风格的安静让它显得冷淡），先调旋钮（签名更醒目、色温更暖），仍不行再换手法。

## 概念卡格式（第 2 阶段，每轮 5 张）

```
C<编号> · <概念名>
母题：      <一个精确的动作或比例>；来自 <名字的首字母 / 名字里的动作 / 业务的哪里>
字：        <读不读得出首字母；读得出时，为什么是元素先于字>
一句话：
形：        <附一张黑白速写；外形、面、主要关系；让概念成立的客观事实>
自查：      <第一眼读成什么（图形感）；剪影与外形像什么、签名在哪、够不够明显（辨识度）；准备用哪种转译手法>
越过：      <第一反应是什么；为什么越过>
方法：
旋钮：      <签名的落法 / 成形方式 / 力度 / 色温（色彩到第 5 阶段再定）>
风险：      <含公共符号撞车与关键场景下是否成立>
延展与参照：<能否长成体系或动态；最接近的思想来源，可在本风格参照之外>
本质：      <删掉了什么，只留下了什么>
签名：      <签名是什么、在哪里、为什么在那里；它的温度来自谁的动作或哪一份坚持；去掉它主体是否还认得出；主体本身是否仍像被精密制造出来的>
```

一轮的 5 张卡，母题必须彼此不同；至少 2 张的主造型语言（视觉上占主导的那一种）与 `cases/index.md` 里的都不同；签名的三种落法至少用到两种。

## 防止同质化

- **候选要宽**：候选母题覆盖至少三处来源；来源越宽，越容易越过「第二反应」。
- **案例只借方法，不借形式**：`cases/` 里出现的具体形状、颜色、工艺，都是那个品牌的答案，不是本风格的规定。
- **母题不重复**：每轮的母题彼此不同，也不能与 `cases/index.md` 登记的真实案例母题相同。本章不举虚构品牌的例子——例子会把同行业的项目锚住。
- **签名要换**：这个风格最容易每次都用同一种签名。同一轮里，签名的形式至少两种，落法至少两种。
- **旋钮要拧**：最终方案至少两个旋钮与所有案例明显不同（对整个项目，不是每张卡；见 `style-dna.md`）。
- **警惕默认答案**：本风格的基因和读过的示范，会把 AI 推向某几类反复出现的形。这里不点名这些答案——点名反而会让人更容易想到它们。用 `exemplars.md` 开头的方法自己识别。
- **按气质判断**：用风格基因与思想坐标的自检判断风格，而不是看元素。
- **交付前对比**：把新方案和已有案例放在一起，一眼要能分开。
